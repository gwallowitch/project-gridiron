# ADR-103 — Forecast-Derived Wind Research

Step 82H achieved complete forecast wind coverage across 2022–2025. Step 82I tests whether the previously promising high-wind signal survives when wind is forecast-derived instead of observed.

The threshold remains 15 mph. Weights tested are 0.10, 0.25, 0.50, 0.75, and 1.00. All observed-weather weights are parked at zero.

This is still research-only because exact historical forecast issuance vintage is not preserved.
