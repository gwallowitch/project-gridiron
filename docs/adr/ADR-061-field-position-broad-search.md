# ADR-061: Field Position Broad Search

74D tests the five validated 74A/74B field-position signals independently on
top of the current promoted baseline: rest 0.20, offensive sack 10.0, punt
return 0.24.

The grid contains one baseline plus 20 single-variable candidates. Independent
testing avoids masking or double-counting because hidden-yards is correlated
with its component field-position measures.

No candidate is promoted in 74D. Promotion requires the existing cross-season
research review.
